# 出題者操作手冊

你會用這個系統幫考場人員出一份「掃 QRCode → 在 LINE 作答 → 立刻看到成績」的測驗。
你**不需要**會寫程式，也**不需要**任何 GitHub、LINE、Google 或 Cloudflare 帳號，只要會用網頁後台。

---

## 一、登入

系統擁有者會私訊給你兩樣東西：

- **管理後台網址**（長得像 `https://xxx.github.io/quiz-repo/admin/`）
- **管理密碼**

打開網址 → 輸入管理密碼 → 按「登入」。成功後會看到上方有四個分頁：**測驗、題庫、發布 / QRCode、作答結果**。

> 🔒 管理密碼可以修改所有測驗，**不要貼在群組、不要傳給別人**。請只在自己的電腦登入。
> 想登出（例如用了公用電腦）按右上角「登出」。
> 登入後，這台電腦會保留 **7 天**的登入狀態（保存的是登入憑證，不是你的密碼）。
> 為了安全，**連續輸錯密碼會被暫時鎖定**（5 次錯誤鎖 5 分鐘，之後越錯鎖越久），請照著提示等時間過去再試。若系統有開啟「我不是機器人」驗證，登入前要先勾選。

## 二、先搞懂三個概念

| 名詞 | 意思 | 例子 |
|---|---|---|
| **類別（題庫）** | 一份「答案清單」，每行一個項目 | 「高硬度岩石」：花崗岩、石英岩、玄武岩… |
| **測驗** | 一場活動用的一組題目，**滿分固定 100 分** | 「岩石大挑戰」 |
| **大題** | 測驗裡的一題。**玩家手機上一頁 = 一個大題**。預設每一題都是大題 | 第 1 大題 |
| **子題** | 大題底下的小題（選用）。一個大題可以分成幾個子題，各自配分 | 第 1 大題 (1)(2)(3)(4) |
| **題目做法** | 兩種 → 見下表 | |

| 題目類型 | 適合 | 你要做什麼 | 系統幫你做什麼 |
|---|---|---|---|
| **自動生成選項** | 現場擺了實物（例如岩石），問「這是什麼」 | 選類別、選正解 | 從同類別隨機抽干擾選項，打亂順序 |
| **手動輸入選項** | 一般知識題 | 打題目、打每個選項、勾正解 | — |

兩種題目玩家看到的樣子一樣，都是 A～E 的選擇題。大題與子題都可以選這兩種做法。

## 三、建立題庫（只有要用「自動生成」才需要）

1. 點「**題庫**」分頁。
2. 左下角輸入類別名稱（例如「高硬度岩石」）→ 按「新增」。
3. 右邊的框框，**一行打一個項目**，例如：
   ```
   花崗岩
   石英岩
   玄武岩
   輝長岩
   片麻岩
   ```
4. 按「儲存」。

**小提醒**
- 一個類別**至少要有 5 個項目**（選項數預設 5 個，要扣掉正解後還夠抽 4 個干擾選項）。
- 空白行、重複項目會自動清掉。
- 修改題庫**不會影響已經建立好的測驗**（選項在你儲存測驗的那一刻就固定了）。

---

## 四、建立測驗

1. 點「**測驗**」分頁 → 右上「**＋ 建立新測驗**」。
2. 填「**測驗名稱**」（玩家會看到）。「說明文字」可選填。
3. 「**測驗代碼**」系統已幫你產生好（例如 `quiz-260918-x7k`），**建立後不能改**，建議不用動它。
   - 想自己取名也可以，但只能用**英文字母、數字、`-`、`_`**（例如 `rock2026`）。
4. 「**允許重複作答**」：
   - **不勾**（預設）→ 每個人只能作答一次，掃第二次只會看到上次成績。**正式活動請維持不勾。**
   - **勾選** → 可以重複作答。**測試時勾起來比較方便**，正式上線前記得取消。
5. 設定「**配分**」（見下面「配分：滿分 100 分」）。
6. 新增題目：

### 自動生成題
1. 按「＋ 自動生成選項題（大題）」。
2. 選「**類別**」→ 選「**正解**」（下拉選單裡就是該類別的項目）。
3. 系統立刻抽好選項並顯示，正解會標綠色 ✓。不滿意按「🎲 重抽選項」。
4. 「選項數」可以改（2～8 個）。「題目文字」可以留空（玩家會看到「請選出正確答案」），也可以寫「請問桌上的這塊岩石是？」

### 手動輸入題
1. 按「＋ 手動輸入選項題（大題）」。
2. 打題目。**題目文字可以留空**（例如題目是看現場的實物或圖片），玩家會看到「請選出正確答案」。
3. 打每個選項，**點選項左邊的圓點 = 設為正解**。
4. 選項可以用「＋ 新增選項」增加、「✕」刪除（2～8 個）。

### 配分：滿分 100 分
測驗最上方的「**配分**」下拉選單：

- **每個大題平均分配**（預設）：系統自動分。除不盡時算到**小數第一位**，多出來的 0.1 分從前面的大題補。
  例如 3 個大題 → 33.4 / 33.3 / 33.3，加起來剛好 100。
- **自訂每個大題的分數**：每個大題右上角自己填分數，例如第 1 題 10、第 2 題 30… **加起來必須剛好 100**。上方會即時顯示「目前合計 ○○ / 100 分」，不是 100 就無法儲存。

### 子題：一個大題分成幾個小題
1. 在大題卡片裡勾選「**這題有子題**」。
2. 可以填「**大題說明**」（選填，會顯示在子題上方），再用「＋ 自動生成子題」或「＋ 手動輸入子題」增加子題。
3. 「**子題配分**」：
   - **平均分配**（預設）：大題的分數平均分給各子題。
   - **自訂**：每個子題自己填分數，**加起來必須等於這個大題的分數**。
     例如大題 40 分 → 子題 5 / 5 / 15 / 15。
4. 子題也可以用 **▲ ▼** 調整順序、「刪除」刪掉。不想要子題了，取消勾選即可（只會保留第 1 個子題）。

### 部分給分：某些錯誤選項也拿分
預設**只有正解拿滿分，其他選項 0 分**。特殊情況才需要開：

1. 在該題（大題或子題）勾選「**部分給分**」。
2. 底下會列出每個選項：正解自動拿滿分；其他選項各填**它能拿幾分**。
   例如 10 分的題目：A（正解）10 分、B 和 C 各 5 分、D 3 分、其餘 0 分。
3. 沒有填的選項 = 0 分，且每個選項的分數不能超過該題配分。

### 調整順序 / 刪除
- 每個大題右上的 **▲ ▼** 可以上下移；電腦上也可以**拖曳左邊的 ⠿**。
- 「刪除」= 刪掉這一個大題。

7. 按下方的「**儲存測驗**」。如果有漏填或配分不對，會用紅框標出是哪一題，並告訴你原因。

> ✅ 儲存後**幾秒內生效**，不用等待。
> 想沿用舊測驗的題目？在「測驗」列表按「**複製**」，會產生一份新的（新代碼）讓你修改。

---

### 玩家看到的樣子
- **一次只看到一個大題**（一頁）。答完按「**下一頁**」，也可以按「上一頁」回去改。
- 畫面上方有「**題目導覽**」按鈕：點開會列出所有大題的號碼（綠色 = 已完成、黃色 = 部分作答、灰色 = 還沒作答），**點號碼就能直接跳過去**，不用一頁一頁翻。
- 最後一頁按「檢視作答總覽」→ 看每個大題選了什麼、哪些還沒答 → 確認送出。
- 每個大題與子題旁邊會顯示它的分數（例如「10 分」）。玩家送出後只會看到**總分**。

## 五、預覽與發布（產生 QRCode）

1. 點「**發布 / QRCode**」分頁 → 選你的測驗。
2. **先預覽**：點「開啟『預覽』」→ 用這場測驗的**真實題目**在電腦瀏覽器作答一次，看得到成績。預覽**不會連 LINE、不會記錄成績**。
3. 確認沒問題，就可以：
   - 「**下載 QRCode（PNG）**」→ 自己排版列印，或
   - 「**列印海報**」→ 直接印出含標題與說明的 A4 海報。
4. ⚠️ **印出來之前，一定要用手機 LINE 實際掃一次**，確認開得到正確的測驗。最好再請另一個人用他的手機掃一次。

## 六、活動結束後：關閉測驗（不刪除）

活動結束後，如果不想再讓人掃碼作答，但又想**保留題目和成績**：

1. 到「**測驗**」分頁，找到那場測驗，按「**關閉作答**」→ 確認。
2. 該測驗會出現紅色「🔒 已關閉」標籤。
3. 之後有人掃 QRCode，只會看到「**這場測驗已結束**」，看不到題目、也不能作答（幾秒內生效）。

**關閉後還在的東西**
- 題目、所有作答紀錄、統計都保留，「作答結果」頁照常能看、能下載 CSV。
- 已經作答過的人，仍然可以在官方帳號聊天室傳「查詢成績」查自己的分數。
- 你自己的「預覽」不受影響。
- 隨時可以按「**重新開放**」恢復。

編輯測驗時，也可以取消勾選「開放作答」來關閉。

---

## 七、活動當天：看結果

1. 點「**作答結果**」分頁 → 選測驗 → 按「載入」。
2. 你會看到：參加人數、平均分、最高分、**每題得分率**（全部人拿到的分數 ÷ 該題滿分；低於 40% 會標紅色，代表這題可能太難或有問題。有子題的大題會逐子題顯示）、每個人的成績。
3. 勾「**每 10 秒自動更新**」，就能在現場用手機/電腦盯著看。
4. 同一個人如果作答了多次，會標「第 2 次作答」。
5. 「下載 CSV」可以匯出成 Excel 開啟。

### 清除作答紀錄（測驗刪除之後）
- **還存在的測驗，作答紀錄不能清除**（避免誤刪活動資料）。
- 如果你把某場測驗**刪除**了，它的作答紀錄還會留在系統裡。在「作答結果」頁下方會出現「**已刪除測驗的作答紀錄**」區塊，可以「**清除**」單一測驗的紀錄，或「**全部清除**」。
- 清除後**無法復原**，請先切到「全部測驗」→「下載 CSV」備份。
- 想清除某場活動的紀錄？先確定不需要了 → 匯出 CSV → 刪除那場測驗 → 再到這裡清除。

## 八、注意事項

**✅ 建議做**
- 正式活動前，用「允許重複作答」跑一遍完整流程（掃碼 → 作答 → 查詢成績），確認沒問題。
- 題目太多的話，玩家在手機上要往下捲很久；現場站著作答的活動，題數抓在玩家幾分鐘內做得完即可。
- 同一個測驗只用在一場活動；下一場用「**複製**」後再修改，QRCode 也重新產生。

**❌ 不要做**
- **活動開始後，不要再修改那場測驗的題目或刪除測驗。** 改了會讓已作答的人與「每題得分率」對不起來，刪除會讓已印出的 QRCode 失效。活動結束想停止作答，請用上面的「**關閉作答**」，不要刪除。
- 不要把管理密碼傳給別人。
- 不要在正式活動時保持「允許重複作答」（除非你就是想讓大家重玩）。

## 常見問題

**Q：登入時說密碼不正確？**
A：確認大小寫與前後有沒有多的空白。仍不行就請系統擁有者確認密碼。

**Q：說「嘗試次數過多，暫時鎖定」？**
A：這是防止亂猜密碼的保護。照畫面上寫的時間等一下再試就好；不要一直重複按，越多次錯誤鎖越久。

**Q：儲存時出現「儲存衝突」？**
A：有另一個人（或你另一個視窗）同時改了這場測驗。重新整理頁面，再改一次。

**Q：自動生成題說類別項目不夠？**
A：到「題庫」補充項目，或把「選項數」調小。

**Q：玩家說看不到分數 / 查詢成績沒反應？**
A：請他確認有按聊天室裡的「送出」。還是不行就通知系統擁有者（後端設定的問題）。

**Q：怎麼把自動題的選項順序固定不變？**
A：已經固定了。選項在你「儲存測驗」的那一刻就決定了，所有玩家看到的都一樣。想換選項就按「🎲 重抽」再儲存。

**Q：題目和答案會被玩家看到嗎？**
A：玩家只會在作答時看到題目與選項；**正解只存在後端，不會傳到玩家手機**，分數也是後端算的。
