# 出題者操作手冊

你會用這個系統幫考場人員出一份「掃 QRCode → 在 LINE 作答 → 立刻看到成績」的測驗。
你**不需要**會寫程式，也**不需要**任何 GitHub、LINE 或 Google 帳號，只要會用網頁後台。

---

## 一、登入

系統擁有者會私訊給你兩樣東西：

- **管理後台網址**（長得像 `https://xxx.github.io/quiz-repo/admin/`）
- **管理密碼**

打開網址 → 輸入管理密碼 → 按「登入」。成功後會看到上方有四個分頁：**測驗、題庫、發布 / QRCode、作答結果**。

> 🔒 管理密碼可以修改所有測驗，**不要貼在群組、不要傳給別人**。請只在自己的電腦登入。
> 想登出（例如用了公用電腦）按右上角「登出」。

---

## 二、先搞懂三個概念

| 名詞 | 意思 | 例子 |
|---|---|---|
| **類別（題庫）** | 一份「答案清單」，每行一個項目 | 「高硬度岩石」：花崗岩、石英岩、玄武岩… |
| **測驗** | 一場活動用的一組題目（題數不限） | 「岩石大挑戰」 |
| **題目** | 兩種做法 → 見下表 | |

| 題目類型 | 適合 | 你要做什麼 | 系統幫你做什麼 |
|---|---|---|---|
| **自動生成選項** | 現場擺了實物（例如岩石），問「這是什麼」 | 選類別、選正解 | 從同類別隨機抽干擾選項，打亂順序 |
| **手動輸入選項** | 一般知識題 | 打題目、打每個選項、勾正解 | — |

兩種題目玩家看到的樣子一樣，都是 A～E 的選擇題。

---

## 三、建立題庫（只有要用「自動生成」才需要）

1. 點「**題庫**」分頁。
2. 左下角輸入類別名稱（例如「高硬度岩石」）→ 按「新增」。
3. 右邊的框框，**一行打一個項目**，例如：
   ```
   花崗岩
   石英岩
   玄武岩
   輝長岩
   片麻岩
   ```
4. 按「儲存」。

**小提醒**
- 一個類別**至少要有 5 個項目**（選項數預設 5 個，要扣掉正解後還夠抽 4 個干擾選項）。
- 空白行、重複項目會自動清掉。
- 修改題庫**不會影響已經建立好的測驗**（選項在你儲存測驗的那一刻就固定了）。

---

## 四、建立測驗

1. 點「**測驗**」分頁 → 右上「**＋ 建立新測驗**」。
2. 填「**測驗名稱**」（玩家會看到）。「說明文字」可選填。
3. 「**測驗代碼**」系統已幫你產生好（例如 `quiz-260918-x7k`），**建立後不能改**，不用動它。
4. 「**允許重複作答**」：
   - **不勾**（預設）→ 每個人只能作答一次，掃第二次只會看到上次成績。**正式活動請維持不勾。**
   - **勾選** → 可以重複作答。**測試時勾起來比較方便**，正式上線前記得取消。
5. 新增題目：

### 自動生成題
1. 按「＋ 自動生成選項題」。
2. 選「**類別**」→ 選「**正解**」（下拉選單裡就是該類別的項目）。
3. 系統立刻抽好選項並顯示，正解會標綠色 ✓。不滿意按「🎲 重抽選項」。
4. 「選項數」可以改（2～8 個）。「題目文字」可以留空（玩家會看到「請選出正確答案」），也可以寫「請問桌上的這塊岩石是？」

### 手動輸入題
1. 按「＋ 手動輸入選項題」。
2. 打題目。
3. 打每個選項，**點選項左邊的圓點 = 設為正解**。
4. 選項可以用「＋ 新增選項」增加、「✕」刪除（2～8 個）。

### 調整順序 / 刪除
- 每題右上的 **▲ ▼** 可以上下移；電腦上也可以**拖曳左邊的 ⠿**。
- 「刪除」= 刪掉這一題。

6. 按下方的「**儲存測驗**」。如果有漏填，會用紅框標出是哪一題。

> ✅ 儲存後**立刻生效**，不用等待。
> 想沿用舊測驗的題目？在「測驗」列表按「**複製**」，會產生一份新的（新代碼）讓你修改。

---

## 五、預覽與發布（產生 QRCode）

1. 點「**發布 / QRCode**」分頁 → 選你的測驗。
2. **先預覽**：點「開啟『預覽』」→ 用這場測驗的**真實題目**在電腦瀏覽器作答一次，看得到成績。預覽**不會連 LINE、不會記錄成績**。
3. 確認沒問題，就可以：
   - 「**下載 QRCode（PNG）**」→ 自己排版列印，或
   - 「**列印海報**」→ 直接印出含標題與說明的 A4 海報。
4. ⚠️ **印出來之前，一定要用手機 LINE 實際掃一次**，確認開得到正確的測驗。最好再請另一個人用他的手機掃一次。

---

## 六、活動當天：看結果

1. 點「**作答結果**」分頁 → 選測驗 → 按「載入」。
2. 你會看到：參加人數、平均分、最高分、**每題答對率**（答對率低的會標紅色，代表這題可能太難或有問題）、每個人的成績。
3. 勾「**每 10 秒自動更新**」，就能在現場用手機/電腦盯著看。
4. 同一個人如果作答了多次，會標「第 2 次作答」。
5. 「下載 CSV」可以匯出成 Excel 開啟。

---

## 七、注意事項

**✅ 建議做**
- 正式活動前，用「允許重複作答」跑一遍完整流程（掃碼 → 作答 → 查詢成績），確認沒問題。
- 題目太多的話，玩家在手機上要往下捲很久；現場站著作答的活動，題數抓在玩家幾分鐘內做得完即可。
- 同一個測驗只用在一場活動；下一場用「**複製**」後再修改，QRCode 也重新產生。

**❌ 不要做**
- **活動開始後，不要再修改那場測驗的題目或刪除測驗。** 改了會讓已作答的人與「每題答對率」對不起來，刪除會讓已印出的 QRCode 失效。
- 不要把管理密碼傳給別人。
- 不要在正式活動時保持「允許重複作答」（除非你就是想讓大家重玩）。

## 常見問題

**Q：登入時說密碼不正確？**
A：確認大小寫與前後有沒有多的空白。仍不行就請系統擁有者確認密碼（連續輸錯會被刻意延遲幾秒，請稍等）。

**Q：儲存時出現「儲存衝突」？**
A：有另一個人（或你另一個視窗）同時改了這場測驗。重新整理頁面，再改一次。

**Q：自動生成題說類別項目不夠？**
A：到「題庫」補充項目，或把「選項數」調小。

**Q：玩家說看不到分數 / 查詢成績沒反應？**
A：請他確認有按聊天室裡的「送出」。還是不行就通知系統擁有者（後端設定的問題）。

**Q：怎麼把自動題的選項順序固定不變？**
A：已經固定了。選項在你「儲存測驗」的那一刻就決定了，所有玩家看到的都一樣。想換選項就按「🎲 重抽」再儲存。

**Q：題目和答案會被玩家看到嗎？**
A：玩家只會在作答時看到題目與選項；**正解只存在後端，不會傳到玩家手機**，分數也是後端算的。
